# References

## Data
- Barker, M. K., Mazarico, E., Neumann, G. A., Smith, D. E., Zuber, M. T., Head, J. W., Sun, X. (2023).
  A New View of the Lunar South Pole from the Lunar Orbiter Laser Altimeter (LOLA).
  *The Planetary Science Journal* 4(9), 183. doi:10.3847/PSJ/acf3e1 (CC BY 4.0).
  Data: NASA GSFC PGDA product 90, doi:10.60903/gsfcpgda-lola-spole, <https://pgda.gsfc.nasa.gov/products/90>
  (the PGDA page asks users to cite this paper).
- Mazarico, E., et al. (2011). Illumination conditions of the lunar polar regions using LOLA topography.
  *Icarus* 211, 1066–1081. doi:10.1016/j.icarus.2010.10.030.
  Data: NASA GSFC PGDA product 69, <https://pgda.gsfc.nasa.gov/products/69>
- JPL Horizons System, NASA Jet Propulsion Laboratory. <https://ssd.jpl.nasa.gov/horizons/>,
  API: <https://ssd-api.jpl.nasa.gov/doc/horizons.html>
- Gazetteer of Planetary Nomenclature, IAU Working Group for Planetary System Nomenclature / USGS
  (`MOON_nomenclature_center_pts.zip`, public domain). <https://planetarynames.wr.usgs.gov/>
- LROC QuickMap (Arizona State University / Intuitive Machines, LRO data), used for cross-checks.
  <https://quickmap.lroc.im-ldi.com/>
